# Lien GitHub — Projet 3

## API de Conversion de Devises

**Dépôt GitHub (public) :**

https://github.com/jacquessiyou4/spring-boot-projet-3-currency-api

---

### Description
Conversion d'un montant entre deux devises via une API externe appelée avec Spring WebClient, avec cache Redis et historique.

### Auteur
SIYOU NOUKIMI JACQUES

### Stack technique
Spring Boot 3.3 · Java 17 · Spring Data JPA · PostgreSQL 15 · Docker Compose · Swagger (springdoc-openapi)

### Documentation de l'API
Une fois l'application démarrée, la documentation Swagger UI est accessible sur :

    http://localhost:8080/api/swagger-ui.html

### Démarrage rapide
```bash
git clone https://github.com/jacquessiyou4/spring-boot-projet-3-currency-api.git
cd spring-boot-projet-3-currency-api
docker compose up -d --build
```

Les instructions détaillées d'installation et de test figurent dans le fichier `README.md` du dépôt.
